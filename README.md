
# Habit Tracker 📊

A simple and visually organized **Habit Tracker created using Google Sheets** to help track daily habits, maintain consistency, and monitor personal progress.

## 📌 Overview

This Habit Tracker is designed to make daily habit tracking simple and easy to visualize. It allows users to record their habits regularly and review their progress over time.

## ✨ Features  

* 📅 Daily habit tracking
* 📊 Progress monitoring
* 🎯 Goal-oriented habit management
* 🎨 Clean and simple spreadsheet design
* 📈 Easy visualization of consistency and progress
* 🔄 Reusable as a monthly habit-tracking template

## 🛠️ Tools Used

* **Google Sheets**
* Spreadsheet formulas
* Conditional formatting
* Data organization and visualization

## 🚀 How to Use

1. Download or make a copy of the Habit Tracker.
2. Add the habits you want to track.
3. Mark your habits each day.
4. Update the tracker consistently.
5. Review your progress and identify areas for improvement.

## 🎯 Purpose

The purpose of this project is to create a simple productivity tool that encourages **consistency, discipline, and better daily habits**.
